# StudyMe – Educational Web Platform

StudyMe is a university project developed in 2025 in collaboration with a teammate. The platform was designed to help students access and organize learning resources in one place.

## Project Overview

This project focuses on building the structure and visual presentation of an educational website. It was developed as a collaborative academic project, with tasks shared between the two team members.

## Technologies Used

- HTML5
- CSS3

## My Contribution

I worked on the website's page structure using HTML and its visual styling using CSS. The work was shared with my teammate, who also contributed to the HTML and CSS development.

## How to View the Project

1. Open the repository on GitHub.
2. Find the `projet2025.html` file.
3. Download the project files and open `projet2025.html` in a web browser.
